# D.E.R.S. v1.1.4.1

## Scope

1. Accepted teacher programs have an owner-only `customTitle` in the existing synchronized board JSON. Canonical week/assignment names are not rewritten. Clearing the alias restores the original.
2. Teacher composer removes only `assignmentRange`; start/end date controls remain. Sending derives the display range from those dates. Existing draft `range` metadata and published assignments are retained.
3. Search is outside the scrollable option list. Previously sticky search and `scrollIntoView` let options move beneath it.
4. The list is focusable. Previously dragging the native scrollbar moved focus to the modal and the outside-focus handler dismissed the popup. Bare list/scrollbar clicks no longer activate the label's hidden select. Actual mouse-drag reproduction is in `tests/v1141-controls.cjs --baseline`.
5. Cloud border-image paint now has corresponding real border space, safe content padding and larger grid gaps. No scale transform or replacement with rectangular cards.
6. Natural green surfaces are intentional and unchanged. Native checkboxes/radios/progress follow the chosen accent; semantic lesson colors remain separate.
7. The existing board was already a CSS Grid, not masonry. Row auto-placement and natural card heights are explicit; unequal-height pairs, subsequent rows and mobile single-column layout have regression coverage.
8. Topic-title requests use existing `quest_change_requests`. A nullable task-local `custom_title` override is set only after the owning teacher approves. Catalog topic metadata, task IDs, historical completion titles, XP and other students are unchanged. Legacy detail/XP requests remain supported. Existing feedback notification preferences apply to results.
9. Focus task selection groups incomplete, non-archived tasks by actual week ID, with collapsed initial groups, date ordering, multiple expanded groups, search and keyboard/touch support. Undated weeks fall back to existing insertion order. Free study remains available.
10. Active focus shows the clock and Pause only. Paused secondary controls use short opacity/translation transitions, honor reduced motion and do not move the clock. Timer/storage/XP engines are unchanged.

## Database Release Safety

- Migration: `supabase/migrations/20261022171931_topic_title_change_requests.sql`.
- Deployment SQL is generated by `scripts/v1141-migration.cjs`; do not replace it with an unguarded ad-hoc production query.
- Preconditions reject a duplicate patch or missing notification infrastructure.
- An atomic, server-only backup in `ders_release_private.app_snapshots`, version `1.1.4.1`, includes application records and prior relevant function definitions. Auth identities are fingerprinted, not exported.
- Sorted short-timeout locks keep snapshots/checks consistent. A mismatch in existing rows, account identities, grants, policies, columns (except the new nullable override) or unrelated functions aborts the transaction.
- No existing app data is seeded, reset, deleted or rewritten by the migration. No RLS policy or auth configuration is changed. Private wrappers and recovery checks are not client-executable.
- The production database remains `jswgagzbetwviamiwcck`. Hosted write tests are restricted to synthetic accounts in `hswipswqulolcwqvcjvi`; browser tests block production API requests.
